- CLIP‑IQA + MUSIQ JSON file: `image_evaluation_results.json`

Both are in the same directory (e.g. `/home/dgarrett/Documents/pictures/2024-09_china/2024-09-10`).

```python
#!/usr/bin/env python3
"""
Compare image quality scores from three models:
- NIMA (from image_evaluator_nima.py, JSON: image_evaluation_nima_results.json)
- CLIP-IQA and MUSIQ (from image_evaluator.py, JSON: image_evaluation_results.json)

For images present in both JSONs (matched by relative_path), this script:
- Lists each model's top K favorite images and K least favorite images
- Summarizes score distributions (count, min, max, mean, median, std)
- Compares overlaps in top images across models
- Shows how each model scores the other models' top images

Usage (typical):

  python compare_image_quality_models.py \
      /home/dgarrett/Documents/pictures/2024-09_china/2024-09-10

You can also override JSON paths if needed:

  python compare_image_quality_models.py /some/dir \
      --nima-json /path/to/image_evaluation_nima_results.json \
      --cm-json /path/to/image_evaluation_results.json \
      --top-k 5
"""

from __future__ import annotations

import argparse
import json
import statistics
from dataclasses import dataclass
from pathlib import Path
from typing import Dict, List, Optional, Tuple

import numpy as np


NIMA_DEFAULT_BASENAME = "image_evaluation_nima_results.json"
CLIP_MUSIQ_DEFAULT_BASENAME = "image_evaluation_results.json"


@dataclass
class JoinedRecord:
    relative_path: str
    nima_score: Optional[float]
    clip_iqa_score: Optional[float]
    musiq_score: Optional[float]


def _load_results(path: Path) -> List[dict]:
    if not path.exists():
        raise FileNotFoundError(f"Results file not found: {path}")
    with path.open("r", encoding="utf-8") as f:
        data = json.load(f)
    if isinstance(data, dict) and "results" in data:
        return data["results"]
    if isinstance(data, list):
        return data
    raise ValueError(f"Unrecognized JSON structure in {path}")


def _index_by_relative_path(records: List[dict]) -> Dict[str, dict]:
    out: Dict[str, dict] = {}
    for r in records:
        rel = r.get("relative_path")
        if isinstance(rel, str):
            out[rel] = r
    return out


def join_results(
    nima_records: List[dict],
    cm_records: List[dict],
) -> List[JoinedRecord]:
    nima_idx = _index_by_relative_path(nima_records)
    cm_idx = _index_by_relative_path(cm_records)

    common_paths = sorted(set(nima_idx.keys()) & set(cm_idx.keys()))
    joined: List[JoinedRecord] = []
    for rel in common_paths:
        nr = nima_idx[rel]
        cr = cm_idx[rel]
        joined.append(
            JoinedRecord(
                relative_path=rel,
                nima_score=_safe_float(nr.get("nima_score")),
                clip_iqa_score=_safe_float(cr.get("clip_iqa_score")),
                musiq_score=_safe_float(cr.get("musiq_score")),
            )
        )
    return joined


def _safe_float(v) -> Optional[float]:
    if v is None:
        return None
    try:
        return float(v)
    except (TypeError, ValueError):
        return None


def extract_scores(
    joined: List[JoinedRecord], attr: str
) -> List[Tuple[str, float]]:
    """
    Return list of (relative_path, score) for the given attribute name
    (e.g. 'nima_score', 'clip_iqa_score', 'musiq_score') where score is not None.
    """
    out: List[Tuple[str, float]] = []
    for r in joined:
        score = getattr(r, attr)
        if score is not None:
            out.append((r.relative_path, score))
    return out


def compute_summary_stats(values: List[float]) -> dict:
    if not values:
        return {
            "count": 0,
            "min": None,
            "max": None,
            "mean": None,
            "median": None,
            "std": None,
        }
    vals = list(values)
    return {
        "count": len(vals),
        "min": min(vals),
        "max": max(vals),
        "mean": statistics.mean(vals),
        "median": statistics.median(vals),
        "std": statistics.pstdev(vals) if len(vals) > 1 else 0.0,
    }


def print_stats(name: str, scores: List[Tuple[str, float]]) -> None:
    vals = [s for _, s in scores]
    stats = compute_summary_stats(vals)
    print(f"\n=== {name} score distribution ===")
    print(f"Count  : {stats['count']}")
    print(f"Min    : {stats['min']:.6f}" if stats["min"] is not None else "Min    : None")
    print(f"Max    : {stats['max']:.6f}" if stats["max"] is not None else "Max    : None")
    print(f"Mean   : {stats['mean']:.6f}" if stats["mean"] is not None else "Mean   : None")
    print(f"Median : {stats['median']:.6f}" if stats["median"] is not None else "Median : None")
    print(f"Std    : {stats['std']:.6f}" if stats["std"] is not None else "Std    : None")


def print_top_bottom(
    name: str,
    scores: List[Tuple[str, float]],
    k: int,
) -> Tuple[List[str], List[str]]:
    """
    Print top-k and bottom-k images for a model.
    Returns (top_paths, bottom_paths).
    """
    if not scores:
        print(f"\n=== {name}: no valid scores ===")
        return [], []

    sorted_scores = sorted(scores, key=lambda x: x[1], reverse=True)
    top_k = sorted_scores[:k]
    bottom_k = sorted_scores[-k:] if len(sorted_scores) >= k else sorted_scores

    print(f"\n=== {name}: top {len(top_k)} images ===")
    for i, (rel, score) in enumerate(top_k, start=1):
        print(f"{i:2d}. {score:8.6f}  {rel}")

    print(f"\n=== {name}: bottom {len(bottom_k)} images ===")
    for i, (rel, score) in enumerate(bottom_k, start=1):
        print(f"{i:2d}. {score:8.6f}  {rel}")

    top_paths = [rel for rel, _ in top_k]
    bottom_paths = [rel for rel, _ in bottom_k]
    return top_paths, bottom_paths


def pearson_correlation(xs: List[float], ys: List[float]) -> Optional[float]:
    if len(xs) < 2 or len(xs) != len(ys):
        return None
    x_arr = np.array(xs, dtype=float)
    y_arr = np.array(ys, dtype=float)
    if np.allclose(x_arr, x_arr[0]) or np.allclose(y_arr, y_arr[0]):
        return None
    corr = np.corrcoef(x_arr, y_arr)[0, 1]
    return float(corr)


def print_model_correlations(joined: List[JoinedRecord]) -> None:
    # Collect pairs for which both scores are present
    pairs = {
        ("NIMA", "CLIP-IQA"): ([], []),
        ("NIMA", "MUSIQ"): ([], []),
        ("CLIP-IQA", "MUSIQ"): ([], []),
    }
    for r in joined:
        if r.nima_score is not None and r.clip_iqa_score is not None:
            pairs[("NIMA", "CLIP-IQA")][0].append(r.nima_score)
            pairs[("NIMA", "CLIP-IQA")][1].append(r.clip_iqa_score)
        if r.nima_score is not None and r.musiq_score is not None:
            pairs[("NIMA", "MUSIQ")][0].append(r.nima_score)
            pairs[("NIMA", "MUSIQ")][1].append(r.musiq_score)
        if r.clip_iqa_score is not None and r.musiq_score is not None:
            pairs[("CLIP-IQA", "MUSIQ")][0].append(r.clip_iqa_score)
            pairs[("CLIP-IQA", "MUSIQ")][1].append(r.musiq_score)

    print("\n=== Pearson correlations between models (same images) ===")
    for (name_a, name_b), (xs, ys) in pairs.items():
        corr = pearson_correlation(xs, ys)
        if corr is None:
            print(f"{name_a} vs {name_b}: not enough variance or data")
        else:
            print(f"{name_a} vs {name_b}: r = {corr:.4f} (n={len(xs)})")


def print_top_overlap(
    model_name_a: str,
    top_a: List[str],
    model_name_b: str,
    top_b: List[str],
) -> None:
    set_a = set(top_a)
    set_b = set(top_b)
    overlap = sorted(set_a & set_b)
    print(f"\n=== Overlap between {model_name_a} and {model_name_b} top images ===")
    print(f"Top-{len(top_a)} of {model_name_a}, Top-{len(top_b)} of {model_name_b}")
    print(f"Overlap count: {len(overlap)}")
    if overlap:
        for rel in overlap:
            print(f" - {rel}")


def print_cross_model_scores_for_top(
    label: str,
    top_paths: List[str],
    joined_by_path: Dict[str, JoinedRecord],
) -> None:
    print(f"\n=== Cross-model scores for {label} ===")
    print("Idx  NIMA        CLIP-IQA   MUSIQ      Image")
    print("---- ----------  ---------  ---------  -----")
    for i, rel in enumerate(top_paths, start=1):
        rec = joined_by_path.get(rel)
        if not rec:
            continue
        ns = f"{rec.nima_score:.6f}" if rec.nima_score is not None else "   None "
        cs = f"{rec.clip_iqa_score:.6f}" if rec.clip_iqa_score is not None else "   None "
        ms = f"{rec.musiq_score:.6f}" if rec.musiq_score is not None else "   None "
        print(f"{i:2d}. {ns:10s}  {cs:9s}  {ms:9s}  {rel}")


def main() -> int:
    parser = argparse.ArgumentParser(
        description="Compare image quality scores from NIMA, CLIP-IQA, and MUSIQ."
    )
    parser.add_argument(
        "directory",
        type=Path,
        help="Directory containing the evaluation JSON files.",
    )
    parser.add_argument(
        "--nima-json",
        type=Path,
        default=None,
        help=f"Path to NIMA JSON (default: <directory>/{NIMA_DEFAULT_BASENAME})",
    )
    parser.add_argument(
        "--cm-json",
        type=Path,
        default=None,
        help=f"Path to CLIP-IQA+MUSIQ JSON (default: <directory>/{CLIP_MUSIQ_DEFAULT_BASENAME})",
    )
    parser.add_argument(
        "--top-k",
        type=int,
        default=5,
        help="Number of top/bottom images to list per model (default: 5).",
    )

    args = parser.parse_args()
    root = args.directory.resolve()
    if not root.exists():
        print(f"Directory does not exist: {root}")
        return 1

    nima_path = (args.nima_json or (root / NIMA_DEFAULT_BASENAME)).resolve()
    cm_path = (args.cm_json or (root / CLIP_MUSIQ_DEFAULT_BASENAME)).resolve()

    print(f"NIMA JSON       : {nima_path}")
    print(f"CLIP/MUSIQ JSON: {cm_path}")

    try:
        nima_records = _load_results(nima_path)
        cm_records = _load_results(cm_path)
    except Exception as e:
        print(f"Failed to load results: {e}")
        return 1

    joined = join_results(nima_records, cm_records)
    if not joined:
        print("No overlapping images found between NIMA and CLIP/MUSIQ results (by relative_path).")
        return 1

    print(f"\nTotal images in NIMA results       : {len(nima_records)}")
    print(f"Total images in CLIP/MUSIQ results : {len(cm_records)}")
    print(f"Images present in both (analyzed)  : {len(joined)}")

    # Build per-model score lists
    nima_scores = extract_scores(joined, "nima_score")
    clip_scores = extract_scores(joined, "clip_iqa_score")
    musiq_scores = extract_scores(joined, "musiq_score")

    # Distribution stats
    print_stats("NIMA", nima_scores)
    print_stats("CLIP-IQA", clip_scores)
    print_stats("MUSIQ", musiq_scores)

    # Top and bottom images per model
    nima_top, nima_bottom = print_top_bottom("NIMA", nima_scores, args.top_k)
    clip_top, clip_bottom = print_top_bottom("CLIP-IQA", clip_scores, args.top_k)
    musiq_top, musiq_bottom = print_top_bottom("MUSIQ", musiq_scores, args.top_k)

    # Correlations
    print_model_correlations(joined)

    # Overlaps in top images
    print_top_overlap("NIMA", nima_top, "CLIP-IQA", clip_top)
    print_top_overlap("NIMA", nima_top, "MUSIQ", musiq_top)
    print_top_overlap("CLIP-IQA", clip_top, "MUSIQ", musiq_top)

    # Cross-model scores for each model's favorites
    joined_by_path = {r.relative_path: r for r in joined}
    print_cross_model_scores_for_top("NIMA top images", nima_top, joined_by_path)
    print_cross_model_scores_for_top("CLIP-IQA top images", clip_top, joined_by_path)
    print_cross_model_scores_for_top("MUSIQ top images", musiq_top, joined_by_path)

    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
def ensure_results_file(
    json_path: Path,
    root: Path,
    evaluator_script: str,
    extra_args: Optional[List[str]] = None,
) -> None:
    """
    Ensure json_path exists. If not, run the given evaluator script:
      python evaluator_script <root> --output json_path [extra_args...]
    evaluator_script is resolved relative to this script if not absolute.
    """
    if json_path.exists():
        print(f"{json_path.name} already exists; using existing results.")
        return

    script_path = Path(evaluator_script)
    if not script_path.is_absolute():
        # Try to resolve relative to this script's directory
        here = Path(__file__).resolve().parent
        candidate = here / evaluator_script
        if candidate.exists():
            script_path = candidate

    print(f"{json_path.name} not found. Generating it with {script_path} ...")

    cmd = [sys.executable, str(script_path), str(root), "--output", str(json_path)]
    if extra_args:
        cmd.extend(extra_args)

    run_command(cmd, cwd=root)

    if not json_path.exists():
        print(f"Expected results file was not created: {json_path}")
        sys.exit(1)
```

why would using a size of 1024 run faster than a size of 512?

---

**Cursor**


It does seem backwards, but a few things can make 1024 feel faster than 512:

**1. GPU utilization**  
With small inputs (e.g. 512), the GPU may be mostly idle: little work per image and the same per-call overhead (kernel launch, memory transfer). At 1024 there’s more work per image, so the GPU is used more efficiently and total time can go down even though each image is “bigger.”

**2. Fixed input size inside the model**  
Many quality models (including some MUSIQ-style ones) resize internally to a fixed size (e.g. 224 or 384). So both 512 and 1024 get resized again inside the model. The cost of your resize + JPEG encode/decode can dominate, and that cost doesn’t always scale linearly with your chosen size; 1024 can sometimes land on a path that’s better optimized (e.g. resolution or batch handling).

**3. Warmup**  
If 512 is run first (cold model load) and 1024 second (model already loaded and warmed up), the 1024 run can be faster overall even though at steady state 512 might be faster per image.

**4. Framework optimizations**  
Libraries (e.g. TensorFlow/cuDNN) often tune for certain sizes. 1024 might use a faster kernel or memory layout than 512 for that specific model.

So in practice: 1024 can run faster than 512 because of GPU underuse at 512, fixed internal resolution, warmup, or framework quirks. If you want the truly fastest setting, time a few sizes (e.g. 256, 512, 1024) after a warmup run and compare per-image time.

### Short answer

**It depends heavily on hardware and bottlenecks, but on a Pi‑class device you might see something like ~1.5× to 3× speedup per image if MUSIQ is the main bottleneck.** In some setups it can be less, in some (with good delegates) more.

### Why the speedup is variable

- **TFLite is optimized for edge CPUs**  
  It uses quantization and fused ops, and can use NEON on ARM. Compared to full TensorFlow (which is heavy on a Raspberry Pi), the same model in TFLite often runs **noticeably faster and with less RAM**.

- **But JPEG + Python overhead may dominate**  
  Your pipeline does:
  - Read image from disk  
  - Resize with Pillow  
  - Encode to JPEG bytes  
  - Run MUSIQ  
  On a Pi 5, file I/O and Pillow resizes can be a big chunk of the total time. If that dominates, then **even a 3× speedup in the MUSIQ call might only give ~20–40% total speedup**.

- **Delegates matter**  
  - On mobile/Android with NNAPI/GPU delegates, TFLite can be **much faster** than TF.  
  - On Raspberry Pi (CPU only, NEON), you’ll likely get a **solid but not insane** speedup.

- **Batching vs. per‑image calls**  
  You’re calling the model once per image. That increases per‑call overhead relative to the compute, which reduces the visible benefit of TFLite vs. TF.

### Rough expectations for your use case

On a Raspberry Pi 5, with your current “one image at a time” pipeline:

- **If MUSIQ compute is the main cost** → TFLite might give **~2×–3× faster** per image.  
- **If resizes / I/O dominate** → overall speedup might shrink to **~1.2×–1.5×**.  

The only reliable way to know for your setup is to time:

1. A run with current TF‑Hub MUSIQ.
