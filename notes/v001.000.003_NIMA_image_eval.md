Generate an second image evaluator script, `image_evaluator_nima.py` that will evaluate images that are 4080x3071 pixels, stored as jpeg files of 2 to 4mb each. As input the script will take directory path. It will then look at each picture in the main and subdirectories. At the end it will save detailed info on the pictures in the directory path in a .json file. Information will include a relative path to the image file and detailed image evaluation results, time taken to evaluate the picture. Also include a total run time for all images, number of images read, basic stats for picture run times and results. If run again on the same directory path, only process those images not previously processed. For image evaluation use NIMA. Write the .json file after each image is evaluated so that if the process is stopped no data is lost.
